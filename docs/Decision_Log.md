## 2026-06-10

- **ИТОГ: машинный JSON — последний блок ответа, лимит 1600 токенов.** До этого отчёты
  молча терялись (обрезка на 600, парсинг первого блока).
- **Завершение сессии не требует памяти ритуала:** кнопка «🏁 Итог» + слова + авто-ИТОГ
  после 25 минут тишины. Отвергнуто: только текстовый триггер «Закончили».
- **Темы скрывают сценарии < 5 слов.** Пустая полка хуже её отсутствия.
- **Времена слотов — минуты от полуночи** (одно число, схема v1 через `user_version`).
  Отвергнуто: отдельные колонки для минут.
- **Ввод часов — текстом «9 14 19»,** не кнопками-часами; `/remind утро 8:30` остаётся
  путём продвинутых, из инструкций убран. Режим ожидания не застревает; опечатка во
  времени получает подсказку (осознанное отступление от «молча» в ТЗ — Ю1).
- **Клавиатура всплывающая (one_time) + placeholder + «гибрид»:** кнопки приходят с
  подсказкой следующего шага после завершений. Отвергнуто: постоянная клавиатура
  (съедала экран во время учёбы). Иконка ⌨ не красится (нативный элемент Telegram) —
  заметность решает placeholder в строке ввода.
- **Доступ-по-заявке:** роли в базе (owner/approved/pending/blocked), карточка владельцу
  с кнопками, `/users`; env-allowlist — аварийный замок поверх. Жена (6635353924) — approved.
- **Полоса комфорта — раздельно по направлениям** recog/prod (общее окно дёргала полоса).
- **Maintenance для known:** box 5 → проверка каждые ~90 дней, провал → в оборот.
  Причина: без извлечения след угасает (Часть 1), can-do-прокси не должен завышать.
- **Счётчики прогресса — только в рамке пути (Nation ~3000),** can-do всегда первый.
  Отвергнуто: «освоено N» как ведущая метрика (против Части 5 канона).
- **Сценарий-сессия одобрена концептуально** (пресеты + грунтовка узлами + мини-цикл
  слова→образец→ролёвка→ИТОГ) — это реализация канона 3.4. **Линейная уроковая система
  отвергнута** (против опоры № 1: «из узлов ученика, а не из общего учебника»).
  Ограничения: полоса скрыта, REVIEW не подменяется. Делается после наполнения базы.
- **A/B-инструментовка признана негодной для вывода** в текущем виде (тайминг включает
  чтение сети; чётность word_id; мерить надо следующее повторение) — редизайн до когорты;
  когорта — после доплотнения сети (корни у 44% слов).
- **Сервер отложен** — активная фаза правок, всё локально; запуск через `run_bot.cmd`
  с автоперезапуском. **Ключи не ротируем** — решение владельца (светились только в
  приватной сессии).
