# English OS — честное позиционирование

## Суть продукта / гипотеза (4 опоры)

**English OS — инженерная, заземлённая на первоисточники и кросс-проверенная ИИ система,
которая учит языку как конструируемой сети.** Чанки и корни — доказательное *содержание*;
инженерия + источники + мульти-ИИ верификация — то, что делает это новым и защитимым.

1. **Декомпозиция и сборка (морфология → сеть).** Корни/приставки/суффиксы → семьи →
   коллокации/чанки → фреймы → сценарии. Анализ (декодировать незнакомое из частей) +
   конструирование (собирать речь из готовых блоков). *Оговорка: корни сильны для
   академической/латинской лексики; высокочастотное ядро — германское.*
2. **Работа с первоисточниками.** Контент на выверенных источниках (этимология, частотные
   корпуса, CEFR, фактчек). Правило: база > генерация, латынь не выдумывать.
3. **Инженерный цикл обучения.** Граф + SRS + модель ученика/память + измерение (A/B);
   LLM — грунтованный компонент, не сам продукт.
4. **Мульти-ИИ верификация («стерео»).** Несколько ИИ-проходов перекрёстно проверяют выводы
   и контент (метод сборки; потенциально — QA-шаг в `enrich` перед `/pending`).

> Сердце — инженерный подход. Чанки/корни/семьи — доказательное содержание внутри него.

---

Принцип: **сеть из 7 слоёв — это АРХИТЕКТУРА обучения, а не доказанный множитель памяти.**
Обещание продукта вешаем на доказанные механики; сеть описываем как способ организации,
теоретически мотивированный (глубина обработки / элаборативное кодирование), но
эмпирически не измеренный именно в этой композиции.

## Что на чём стоит

| Утверждение | Статус | Как использовать в коммуникации |
|---|---|---|
| Интервальное повторение работает | 🔬 доказано (мета-анализы) | можно обещать прямо |
| Коллокации/чанки → беглость | 🔬 доказано | можно обещать прямо |
| Продуктивный recall (RU→EN) для зрелых слов | 🔬 доказано | можно обещать прямо |
| Баланс ввод+вывод (i+1) | 🔬 доказано | можно обещать прямо |
| Семьи слов / морфология (для латинизмов) | 🔬 доказано (с оговоркой про германское ядро) | обещать с оговоркой |
| **Подача слова сразу во всех 7 слоях даёт прирост vs плоская карточка** | 🟧 теория, НЕ измерено | НЕ обещать как факт; описывать как архитектуру |
| «Английский меняет мышление» | 🟧 слабый Уорф | не продавать «смену сознания», только «новую языковую привычку» |

## Готовые формулировки УТП (честные)

1. «Учим слово в его связях — корень, семья, коллокации, сценарий, фрейм — так, как
   смысл и хранится в памяти. А запоминание держим на проверенном: интервальном
   повторении и продуктивной речи.»
2. «Не список слов, а операционная система: ядро (SRS + продукция) доказано работает,
   а слои дают контекст, без которого слово не превращается в речь.»
3. «Тренажёр делового английского для русскоязычных: проверенные механики усвоения
   плюс заточка под английский порядок слов (SVOMPT) и под типичные структурные ошибки.»
4. «Мы измеряем прогресс по делу (что ты можешь сказать/написать в рабочей ситуации),
   а не по числу „пройденных“ слов.»

## Так НЕ говорим → Так говорим

| ❌ Не говорим (переобещание) | ✅ Говорим (честно) |
|---|---|
| «Сеть → запоминаешь в 3 раза быстрее» | «Сеть organizует обучение; скорость даёт SRS» |
| «Доказано: слои эффективнее карточек» | «Слои теоретически мотивированы; эффект измеряем» |
| «Английский перепрошивает мышление» | «Формируем новую языковую привычку (порядок слов)» |
| «90% слов — из корней, учи корни» | «Корни помогают с академической/латинской лексикой» |

## Дисциплина для команды и для ИИ-аналитика
- Любое утверждение об эффективности маркируем: 🔬 доказано / 🟧 теория / ⏳ измеряем.
- «Сетевой буст» до RCT — это **гипотеза продукта**, а не факт. В продукте заложена
  инструментовка (вариант карточки + время ответа в `reviews`), чтобы проверить его
  на когорте позже. На n=1 — только направленный сигнал, не доказательство.
