# English OS — инструкции и руководства

*Статья базы знаний · пошаговые действия для пользователей и для сотрудников/админов*

---

## Часть 1. Для пользователя

### Как начать (первый запуск)

1. Откройте бота English OS в Telegram.
2. Нажмите **/start**.
3. Выберите комфортный темп: «С самых основ», «Уже кое-что знаю» или «Уверенно общаюсь».
   Это не экзамен — тренер подстроится по ходу.
4. Тренер сразу предложит первые слова. Можно начинать.

### Ежедневный ритм (рекомендация)

- **Утро:** откройте меню (/start) → «🌅 Новые слова». Разберите пару новых слов.
- **День:** /start → «☀️ Повторение». Пройдите карточки — это пара минут.
- **Вечер:** /start → «🎭 Сценарий». Потренируйте речь в ролевой ситуации.
- **По желанию:** /read — короткий текст под ваш уровень; «🗣️ Поток» — просто поболтать.

### Основные команды

| Команда / действие | Что делает |
|---|---|
| **/start** | Главное меню и выбор режима |
| **«учим invest, generate»** | Разобрать конкретные слова и взять их в учёбу |
| **/read** | Текст для чтения под ваш уровень |
| **/topics** | Учить слова по теме (по смыслу или по сценарию) |
| **/progress** | Что вы уже можете сказать/написать в работе |
| **/mistakes** | Ваши повторяющиеся ошибки |
| **/pace** | Сменить темп / сложность |
| **/remind 9** | Напоминать о повторении в 9:00 (·/remind off — выключить) |
| **/add deadline stakeholder** | Предложить новые слова в учёбу |
| **Голосовое сообщение** | Тренер распознает речь и ответит |
| **«Закончили» / «Стоп»** | Завершить занятие — тренер даст итог сессии |

### Как проходит повторение

Тренер показывает слово; вы вспоминаете ответ и нажимаете «👁 Показать ответ», затем честно
отмечаете «✅ Вспомнил» или «❌ Забыл». От этого зависит, когда слово вернётся: вспомнили —
интервал растёт, забыли — слово вернётся скоро. Чем зрелее слово, тем строже спрос: сначала
достаточно узнать перевод, потом нужно самому сказать его по-английски.

### Как завершить занятие

Напишите «Закончили» (или «Стоп»). Тренер подведёт итог: что обсудили, что повторили, какие
ошибки заметил и что взять на завтра. Прогресс сохранится автоматически.

## Часть 2. Для сотрудника / администратора контента

> Эти действия касаются поддержания базы знаний продукта и доступны ответственному за
> контент (владельцу). Обычным пользователям они не видны.

### Модерация новых слов (очередь подтверждения)

Когда пользователь предлагает слова (через «/add» или по ходу занятия), они попадают в
**очередь на подтверждение**, а не сразу в базу.

1. Команда **/pending** — показать первое слово из очереди с его разбором (перевод, идея,
   коллокации, пример).
2. Проверьте корректность данных.
3. Нажмите **«✅ Добавить»** — слово войдёт в базу и станет доступно для изучения, либо
   **«🗑 Отклонить»** — слово уйдёт из очереди.
4. Бот сам не допускает дубликатов: если слово уже есть, оно не задвоится.

### Пополнение базы словами

- **Через бота:** команда `/add слово1 слово2` — тренер сам соберёт разбор (перевод, связи,
  пример) и положит результат в очередь /pending на проверку человеком.
- **Пакетно (со стороны):** инструмент пополнения принимает список слов, прогоняет их через
  ИИ в полный разбор по слоям, проверяет формат и складывает в ту же очередь /pending.
  Подтверждение всегда остаётся за человеком.

### Загрузка и обновление контента

- Базовый контент заливается из исходного файла один раз («посев»). Повторная заливка
  безопасна: существующие записи обновляются, **прогресс пользователей не теряется**.
- Канон данных — внутренняя база; исходные файлы (таблица/JSON) служат источником для
  первичной заливки и архива.

### Резервные копии

- Снимок базы делается автоматически в конце учебных сессий и складывается в папку резервных
  копий. Это страховка от потери прогресса.

### Принцип работы с данными (важно)

- **База — источник истины.** Тренер опирается на проверенные данные, а не на свободную
  выдумку: этимологию (корни) и шаблоны фраз берёт из выверенной базы.
- Любое новое слово проходит через проверку человеком перед попаданием в обучение.
