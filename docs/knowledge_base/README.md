# База знаний ИИ-ассистента «English OS»

Набор статей, на которые опирается ИИ-ассистент при ответах пользователям. Каждая статья —
отдельная тема, чтобы ассистент подтягивал нужный кусок под конкретный вопрос.

> **Статус продукта:** ранний доступ (MVP). Сейчас English OS бесплатен для ограниченного
> круга пользователей; цены и тарифы в базе — планируемые, не окончательные.

## Состав

| Файл | Тема |
|---|---|
| `00_product_overview.md` | О продукте: что это, для кого, в чём суть |
| `01_faq.md` | Частые вопросы и ответы |
| `02_specs_and_pricing.md` | Состав продукта, тарифы, технические требования |
| `03_usp.md` | Уникальное торговое предложение (отличия от конкурентов) |
| `04_policies.md` | Политики: доступ, оплата, возврат, поддержка, данные |
| `05_guides.md` | Инструкции для пользователя и для администратора |
| `06_assistant_glossary.md` | Глоссарий терминов + тон и границы ассистента |
| `07_dialog_examples.md` | Примеры диалогов: вопрос пользователя → ответ ассистента |

## Как использовать

- **Для ИИ-ассистента:** загрузить статьи как источник знаний; ассистент отвечает на их
  основе, разделяя доказанное и гипотезы и не выдумывая того, чего в базе нет.
- **Для человека:** читать с `00` — он даёт общий контекст, остальные раскрывают детали.
