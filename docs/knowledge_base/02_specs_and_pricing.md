# English OS — состав продукта, тарифы и требования

*Статья базы знаний · спецификации продукта и услуг*

> **Статус продукта:** ранний доступ (MVP). Тарифы и цены ниже — **планируемые**, не
> окончательные. На этапе раннего доступа English OS бесплатен для ограниченного круга
> пользователей.

## Что это за продукт

English OS — это ИИ-тренер делового английского, работающий как бот в Telegram. Пользователь
общается с тренером текстом или голосом; тренер опирается на выверенную базу слов и
методику, а не на свободную генерацию.

## Что входит (возможности)

| Возможность | Что делает |
|---|---|
| **Новые слова** | Каждый день — несколько новых слов с разбором: связи, пример, ситуация (не просто перевод) |
| **Повторение (карточки)** | Слова возвращаются на повтор ровно тогда, когда их пора освежить; оценка «вспомнил / забыл» |
| **Ролевые сценарии** | Тренер играет собеседника (инвестор, клиент, коллега); разбор ошибок — в конце, не перебивая |
| **Чтение под уровень** | Короткий текст, где почти всё знакомо и лишь немного нового — «понятный ввод» |
| **Свободный разговор** | Живая беседа на английском с мягкими подсказками |
| **Учёба по темам** | Выбор слов по смыслу или по рабочему сценарию |
| **Голосовой ввод** | Можно отправлять голосовые — тренер их распознаёт |
| **Прогресс «по делу»** | Видно, что вы уже можете сказать/написать в работе (в стиле CEFR «могу сделать X») |
| **Работа над ошибками** | Тренер копит ваши типичные структурные ошибки и показывает повторяющиеся паттерны |
| **Напоминания** | Ежедневное напоминание о повторении в удобный час |

## Технические требования

- **Платформа:** Telegram (мобильный, десктоп или веб) — отдельное приложение не нужно.
- **Устройство:** любой смартфон или компьютер с Telegram.
- **Интернет:** обязателен (тренер работает через облако).
- **Голос:** для голосового ввода нужен микрофон; функция опциональна.
- **Язык интерфейса:** русский. **Язык обучения:** английский.

## Для кого

Русскоязычный взрослый уровня примерно A2–B2, которому английский нужен для работы:
переговоры, письма, встречи, собеседования. Не предназначен для изучения «с нуля» и не
заменяет языковую среду — снимает рутину запоминания и сборки фраз.
